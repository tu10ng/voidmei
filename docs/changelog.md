# 版本亮点

!!! info "完整更新记录"

    逐版本改动见仓库中的[更新日志.txt](https://github.com/matrixsukhoi/voidmei/blob/master/更新日志.txt)与 [Releases](https://github.com/matrixsukhoi/voidmei/releases) 页面，本页只收录里程碑。

| 版本 | 亮点 |
|------|------|
| **v1.0** | 初版发布：8111 轮询、飞行状态面板、试飞图表 |
| **v1.20** | **FM 拆包**上线：blkx 解析器读取机型关键性能数据；新增攻角显示与 SEP 稳定化 |
| **v1.38** | **语音告警**上线：健康监测 + 十余种条件触发的 TTS 语音 |
| **v1.50** | 计算体系修正：滑动平均处理误差与跳变，修正转弯过载/转弯率/SEP 计算（感谢隐居寒天、Zetta） |
| **v1.53–1.54** | 相对能量 E 显示、FM 对比功能、默认字体改为更纱黑体等距 |
| **v1.548–1.569** | 可变后掠翼机型全套适配、新襟翼限速告警逻辑、无线电高度多径提示、机动指数条 |
| **v1.580** | **所见即所得**：主界面实时预览与修改，MiniHUD 襟翼角条 |
| **v1.584** | 发布渠道迁移至 GitHub Releases，分发包瘦身 104 MB → 56 MB |
| **v1.586** | **FM 数据在线自动更新**：游戏版本更新后启动即自动拉取；自动跟随系统代理；直升机告警适配 |

!!! tip "保持最新"

    程序启动时会自动检查新版（v1.60 起），更新方式见[安装 → 升级与配置迁移](install.md#升级与配置迁移)。
