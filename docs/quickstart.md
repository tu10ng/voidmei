# 快速上手

## 三步开跑

1. 游戏设为**全屏窗口（无边框）或窗口模式**运行（试飞与自定义模式需打开「允许使用网页界面」开关，详见[安装](install.md#系统要求)）
2. 运行 VoidMei，打开需要的面板并拖动到合适位置——所有开关与选项的影响**实时渲染，所见即所得**
3. 进入对局，悬浮窗自动出现数据；游戏失焦时自动隐藏，切回游戏自动恢复

## 推荐初始配置

首次使用建议开启两个面板，覆盖大多数玩家关心的核心参数：

- **自定义 HUD → 自定义HUD on → 最小HUD on**：空战核心信息高度集成（攻角、可用攻角、SEP 能量、耐热告警等，图解见[MiniHUD](features/minihud.md)）
- **发动机状态 → 发动机面板 on → 显示耐热时 on**：动态计算引擎在当前温区还能运行多少秒，有效防止烧引擎

### 语音告警调整

语音告警开箱即用，可以按口味调整：

- 在设置的语音告警页调整音量，或逐条关闭/替换某条告警
- 大多数告警也可直接删除 `voice/` 目录下对应的 wav 文件，不影响程序运行
- 全真玩家推荐把攻角告警（`aoaCrit`）换成更醒目的音效（如电话铃），详见[语音告警](features/voice.md#自定义语音)

### 攻角告警阈值建议

MiniHUD 的攻角指示条与攻角数值变红条件可在「最简HUD设置」中调整：

- 历史模式玩家：两个阈值都设 25%
- 全真模式玩家：数值阈值 20%、指示条阈值 25%

## 进阶技巧

- **飞行中动态调整**：随时点击任务栏的 VoidMei 图标打开设置，布局即时生效，无需退出对局
- **FM 拆包信息**：飞行中按 <kbd>P</kbd> 随时开关，方便查看襟翼限速等数值的同时不影响视线
- **新手捷径**：向身边在用的朋友索要其程序目录下的 `ui_layout.user.cfg`（保存着对方的全部设置），用「全局设置 → 导入配置」直接导入；没有这样的朋友可以在 B 站私信"隐居寒天"或其他使用的 UP 主
- **更新提醒**：v1.60 起启动时自动检查新版，更新请到 [Releases](https://github.com/matrixsukhoi/voidmei/releases/latest) 下载，升级方式见[安装 → 升级与配置迁移](install.md#升级与配置迁移)

!!! tip "分析记录文件乱码？"

    「记录与分析」导出的 csv 用 Excel 打开若为乱码，请以 UTF-8 编码导入，或使用 WPS 等其他软件。
