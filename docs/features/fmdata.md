# FM 数据

FM（Flight Model）拆包是 VoidMei 全部[智能算法](algorithms.md)的数据底座：程序附带离线拆包的气动模型数据库（`data/aces` 下的 blkx 文件），飞行中实时读取当前机型的关键性能参数。

!!! warning "EULA 提示"

    拆包/逆向工程是可能违反战争雷霆 EULA 1.2 与 3.2 条款的行为。附带数据库由网络途径获得，若担心风险可自行删除 `data/aces` 目录（程序其余功能不受影响，但 FM 相关指标与告警会退化为不可用）。

## 飞行中查看

- **FM 数据面板**：设置中「FM数据 → 启用Overlay」，展示当前机型的各项参数；飞行中按 <kbd>P</kbd> 随时开关，查看襟翼限速等数值的同时不影响视线
- **飞机对比**：「记录与分析」中可将当前机型与其他机型对比（v1.53 起），对比项以文本形式呈现
- 面板内的开关按需裁剪显示项：临界速度、过载极限、襟翼限速、三舵效能、加力信息、耐热恢复、千米过载、转动惯量、升力参数、阻力参数，以及各气动部件（机翼无襟翼/满襟翼、机身、垂尾、平尾）明细；功率曲线可切换 WEP 模式与选定速度

## 指标物理含义

| 指标 | 含义与用法 |
|------|-----------|
| 临界速度 | 失速速度与结构允许最大速度 |
| 三轴转动惯量 | 转动惯量越小越敏捷，操纵感越轻盈 |
| 展弦比 | 翼展² ÷ 翼面积。展弦比越大，诱导阻力越小，机动能量损失越低 |
| 翼展效率 | Oswald 翼展效率因数。越大诱导阻力越小 |
| 诱导阻力因数 | 1/(π × 翼展效率 × 展弦比)，与诱导阻力线性相关 |
| 诱导阻力加速度系数 | 诱导阻力因数 ÷ 半油重量。衡量无动力条件下以最大升力盘旋时的能量损失程度 |
| 三舵面有效速度与锁舵因数 | 有效速度越高、锁舵因数越低，越不容易在高速锁舵 |
| 主阻力面积因数 | 近似平飞时的阻力系数（略小于实际值，平飞仍有小负攻角诱导阻力） |
| 主升力面积因数载荷 | Σ(部件最大升力系数 × 部件面积) ÷ 半油起飞重。安东星各机型升力系数差异大，比翼载荷更能反映瞬时盘旋性能，直接反映回转半径 |
| 主阻力面积加速度系数 | 主阻力面积因数 ÷ 半油重量。衡量无动力滑翔的存速能力——该值越小，俯冲/滑翔存速越好 |
| 临界攻角 | 升力曲线取得最大升力时的攻角，超过则该气动部件升力下降 |

**对比机型时怎么用**：动能量与盘旋看主升力面积因数载荷 + 临界攻角；持续机动存能看展弦比/翼展效率/诱导阻力加速度系数；高速掠袭与存速看主阻力面积加速度系数；高速操纵性看三舵面有效速度与锁舵因数。

## 这些数据如何参与计算

FM 拆包不是只读来展示的——[智能算法](algorithms.md)的每一项都以它为输入：

| FM 数据 | 参与的计算 | 计算原理 |
|---------|-----------|----------|
| 最大升力系数 × 翼面积、临界攻角 | [失速速度](algorithms.md#精准控速)（随当前油量与襟翼开度实时变化） | [失速速度](../theory.md#失速速度) |
| 解体表速 VNE / 解体马赫 MNE（含各后掠档） | [智能速度](algorithms.md#精准控速)临界区、表速/马赫超速告警（95% 阈值） | [马赫数与速度临界比](../theory.md#马赫数与速度临界比) |
| 三舵有效速度与锁舵因数 | 速度条锁舵区、方向舵/副翼劣化语音告警 | 同上 |
| 机翼临界气动载荷 | [真实过载极限](algorithms.md#放心拉杆)（随油量实时变化） | [真实过载极限](../theory.md#真实过载极限) |
| 襟翼吹飞速度表 | [智能襟翼](algorithms.md#直观控襟翼)极限开度，精准到个位 | [智能襟翼极限开度](../theory.md#智能襟翼极限开度) |
| 发动机温度档（WorkTime/RecoverTime） | [引擎耐热时](algorithms.md#精准控温)倒计时 | [引擎耐热时](../theory.md#引擎耐热时) |
| 增压器各级参数（临界高度/增压比/WEP 转速） | 功率曲线、[增压器档位](algorithms.md#增压器不掉档)最优档提示 | [活塞功率模型](../theory.md#活塞功率模型) |
| 进气效率系数 | 活塞功率的冲压效应修正 | [大气模型](../theory.md#大气模型isa) |

FM 数据缺失时（未带 data 目录或机型未收录），相关计算按"隐藏/保持上次值"降级，其余遥测显示功能不受影响。

## 在线自动更新

v1.586 起，游戏版本更新后**无需等待程序发版**：

- 启动时自动检查并静默下载最新 FM 数据，右下角显示进度，下载完成**即时生效**
- 设置中可关闭「自动更新FM数据」，也可手动触发检查
- 设置面板的版本信息行显示当前 FM 数据的游戏版本号与打包日期
- 更新走 GitHub Release 直链，自动跟随系统代理（Clash/v2rayN"系统代理"模式无需额外配置）

高级用户也可自行拆包替换：使用 [wt_ext_cli](https://github.com/Warthunder-Open-Source-Foundation/wt_ext_cli) 生成 `data/` 目录覆盖即可。
