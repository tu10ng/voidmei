# 语音告警

满足触发条件时播放语音提示，覆盖飞行安全与引擎健康两大类，默认语音由 TTS 合成。所有告警均可在设置的「语音告警」页逐条开关、调节音量，或替换为自己的音频。

## 触发条件一览

### 飞行安全

| 告警 | 触发条件 | 语音文件 |
|------|---------|----------|
| 临界攻角 | 可用攻角达到 95% 及以上、或攻角达到失速攻角 95% 及以上时**持续告警**，主要用于全真和切 | `aoaCrit.wav` |
| 高攻角 | 可用攻角/攻角达到失速攻角 75% 时告警，主要用于全真和切 | `aoaHigh.wav` |
| 失速 | 表速达到计算出的**真实失速速度**时持续告警（挂弹及气动受损时有少许偏差） | `warn_stall.wav` |
| 表速过高 | 达到解体表速的 95% 或更高时持续告警 | `warn_ias.wav` |
| 马赫数过高 | 达到解体马赫数的 95% 或更高时持续告警 | `warn_mach.wav` |
| 过载告警 | 过载达到**真正会断**时告警，比游戏内极限更贴近真实；响后 1 秒内恢复不会断 | `warn_loadfactor.wav` |
| 襟翼超速 | 比游戏内告警极限更保守的襟翼超速告警，建议与[襟翼指示器](minihud.md#智能襟翼指示器)一起使用 | `warn_flap.wav` |
| 起落架 | 起落架高于极限速度 93% 且仍未完全回收时告警 | `warn_gear.wav` |
| 高度过低 | 按当前下降率 10 秒内撞击**海平面**时告警 | `warn_altitude.wav` |
| 地形告警 | 按当前下降率 10 秒内撞击**地面**时告警 | `warn_terrain.wav` |
| 下降率过大 | 开启起落架时下降率高于 10 m/s 持续告警 | `warn_highvario.wav` |
| 方向舵劣化 | 表速超越方向舵锁舵速度瞬间告警一次，此时方向舵无法满偏 | `rudderEff.wav` |
| 副翼劣化 | 表速超越副翼锁舵速度瞬间告警一次，此时副翼无法满偏 | `aileronEff.wav` |

### 引擎状态

| 告警 | 触发条件 | 语音文件 |
|------|---------|----------|
| 引擎过热 | 引擎进入最后 300 s [耐热时](algorithms.md#精准控温)时告警（通常是倒数第二段耐热区间） | `warn_engineoverheat.wav` |
| 油压过低 | 引擎出现损坏时告警一次 | `warn_lowpressure.wav` |
| 引擎失效 | 负 G 断油告警 | `fail_engine.wav` |
| 燃油不足 | 剩余燃油仅剩起飞时的 10% | `warn_lowfuel.wav` |
| 燃油耗尽 | 燃油空时告警一次 | `fail_nofuel.wav` |
| 转速过低 | 引擎转速仅为应有转速 70% 以下时持续告警，提示桨距设定问题或发动机损伤 | `warn_lowrpm.wav` |
| 转速过高 | 引擎转速达极限转速 105% 及以上时持续告警，提示桨距设定或定距桨超速问题 | `warn_highrpm.wav` |
| 增压器档位 | 最佳增压器档位需要切换时提示，仅多档机械增压器活塞引擎，建议与[引擎控制面板](algorithms.md#增压器不掉档)的增压器显示同用 | `warn_compressor.wav` |
| 减速板展开 | 开启减速板时持续告警，防止忘关 | `warn_brake.wav` |

另有**启动音效**（`start1.wav`）：进入对局、成功连接 8111 端口时的提示音。

!!! tip "锁舵提示也会播报"

    语音告警会播报锁舵提示（方向舵/副翼劣化），配合 MiniHUD [速度条](minihud.md)的锁舵区使用效果最佳。

## 自定义语音

三种方式，按需取用：

**1. 设置页逐条配置**：「语音告警」页有每条告警的独立配置与总音量滑条。

**2. 全局语音包**：设置页顶部可选择或导入全局语音包，自动覆盖其支持的语音——用任意**同名称同后缀**的音频文件替换即可（例如用真实飞机制造商的警铃）。玩得花的经典操作：把临界攻角告警（`aoaCrit`）换成电话铃声，全真模式与"切"玩家强烈推荐。

**3. 直接删改 `voice/` 目录**：

- 删除某条告警对应的 wav 文件即可关闭该条告警，**不影响程序运行**
- 替换同名 wav 实现自定义语音——**只支持 wav 格式**，其他格式请先转换

!!! warning "喷气机注意"

    转速类告警针对活塞引擎的桨距逻辑设计；部分喷气机（如幻影 2000C）的告警逻辑已专门适配，异常误报请提 [issue](https://github.com/matrixsukhoi/voidmei/issues)。
