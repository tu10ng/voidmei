# 个性化定制

## 所见即所得

设置主界面本身就是实时画布（v1.580 起）：任何开关、滑条、颜色的改动**即时渲染**到悬浮窗预览，每一项都附有中文说明与效果演示图，调到满意再进游戏。

设置界面随时可开：桌面直接打开，或飞行中点击任务栏的 VoidMei 图标。

## 面板摆放

- 所有悬浮窗（MiniHUD、飞行信息、发动机、地平仪、舵面值等）可**自由拖拽**到任意位置，位置自动保存
- 每个面板有独立的大小/缩放设置（字体大小或像素宽高）
- 游戏失焦时自动隐藏、切回自动恢复（可在设置关闭该行为）

## 配置文件

全部设置（面板开关、位置、字体、颜色、告警阈值等）保存在程序目录下的 **`ui_layout.user.cfg`** 一个文件里：

- **备份/换电脑**：保存这个文件即可，之后放进新版程序目录，或在新版中「导入配置」导入
- **使用他人配置**：向对方索要该文件，在「全局设置」中点「导入配置」，拖放或选择文件导入（仅支持 `.cfg` / `.bak` 文件）
- **自动备份**：导入、升级与恢复出厂前都会自动备份为 `ui_layout.user.cfg.bak`，想撤销本次操作就把备份导入回去
- **自动合并**：导入时会与当前版本的模板自动合并——已有设置全部保留，新版本新增的选项按默认值出现，不会缺新功能

!!! warning "两点注意"

    - **切勿直接复制替换文件**，务必走「导入配置」——直接替换在版本不一致时会缺失新功能
    - 程序目录下的 `ui_layout.cfg` 是出厂模板，请勿修改
    - 从 v1.580 及更早版本升级：旧设置文件（`config/config.properties`）与新配置系统不兼容、无法迁移，需在设置界面重新调整或导入他人的 `ui_layout.user.cfg`

## 字体

- **MiniHUD 必须使用等宽字体**，在「最简HUD设置 → 等宽字体」下拉框中选择，默认更纱黑体等距（Sarasa Mono SC）
- 因字体授权原因，v1.584 起不再内置 DIN Pro 字体（开源字体照常内置）；需要者可自行将字体文件放入 `fonts/` 目录
- 高级设置中可调整字体颜色（RGBA）、描边方式与抗锯齿

## 自定义文本

修改 `lang/cur.properties` 可替换程序中显示的几乎所有文本，也可用于本地化。

## 分析记录

「记录与分析」支持飞行数据的记录与图表生成（高度-时间-功率、速度-滚转率-过载包线等，csv 为 UTF-8 编码，Excel 打开乱码请按 UTF-8 导入），并内置[飞机对比](fmdata.md#飞行中查看)功能。
