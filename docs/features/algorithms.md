# 智能算法

这一页的每个能力都建立在同一件事上:FM 拆包数据 + 实时遥测的本地计算。不是转发仪表读数,是替你算好答案。按"控飞机"的顺序排:速度、襟翼、温度、增压器、功率、盘旋、结构。

## 精准控速

速度的两头都是死路:低速端失速,高速端解体,中间还埋着锁舵——表速一过某个点,舵面就压不满,拉杆变成空拉。

VoidMei 的速度条把三条线全画出来:

- **失速线随你变**——按当前油量与襟翼开度实时计算。烧掉半箱油,失速速度跟着降,告警跟着准;满襟翼低速盘旋,临界值立刻收紧。挂弹和受损会有少许偏差,除此之外与真实失速同步。
- **解体盯更近的那个**——表速与马赫数哪个先到解体极限,告警就盯哪个(95% 触发)。马赫数不用游戏给的两位小数粗值,而是按大气模型自己算([怎么算](../theory.md#马赫数与速度临界比)),高空告警不迟不早。
- **锁舵区有声音**——方向舵、副翼各自的锁舵速度来自 FM,表速一进区间,语音立刻告诉你"这个舵现在压不满了",配合速度条的红区一目了然。

速度条在 MiniHUD 左侧(「油门条/速度条」开关,默认开启)。直升机自动屏蔽失速与锁舵类告警——那是固定翼的病。

## 直观控襟翼

空战里襟翼的收放时机直接决定谁占内圈。放少了转不过对面,放多了襟翼吹飞、机体受损——而游戏自带的告警响起来时,你多半已经超了。

VoidMei 把答案直接画在襟翼条上:**当前速度下,襟翼最多能放多少**。从 FM 的吹飞速度表实时反推,精准到个位数——收与放还取不同的安全沿。贴着极限开度飞,每一圈把襟翼收益榨满,又绝不越线。

襟翼条在 MiniHUD 上(「智能襟翼指示器」,默认开启);语音「襟翼超速」比游戏告警更早、更保守。计算细节见[智能襟翼极限开度](../theory.md#智能襟翼极限开度)。

## 精准控温

烧引擎是螺旋桨玩家最冤枉的死法:明明赢了狗斗,回头一哆嗦引擎红了。

VoidMei 直接给你倒计时:**这台引擎还能烧多少秒**。不是"温度偏高"式的模糊提示,是个位精度的秒数——温度每升一档,剩余时间实时扣减;收油门、开散热,看着数字回血。把引擎压在极限边缘榨动力,心里有数。

三个入口:发动机状态面板的「显示耐热时」(快速上手的必开项)、MiniHUD 罗盘内的红色告警条(转满即接近故障)、语音(最后 300 秒叫你)。

它不是查表读数,是对你整段飞行热史的积分仿真——频繁搓油门跳温时略有偏差,稳定控温精确无误。见[引擎耐热时](../theory.md#引擎耐热时)。

## 增压器不掉档

手操增压器的飞机,换挡时机全靠背高度表——背错一档,功率凭空少一截,对拼时就是输。

VoidMei 对每个增压档算出当前高度/速度下的真实功率,取最大者告诉你**现在几档最优**。引擎控制面板上理想档位与实际档位并排显示(「增压器」开关),该换挡时语音直接提示,手操增压器从此不用背数字。

仅多档机械增压器的活塞机适用,油门不满时不做判断。功率怎么算见[活塞功率模型](../theory.md#活塞功率模型)。

## 看穿功率余量

"我的引擎现在发挥了几成?"——动力量回答这个问题:当前功率(推力)与这台引擎理论极限的百分比,活塞机与喷气机都有效。

高空衰减了多少、散热开口的代价、加力提升了几个点,看一个数就明白。该换增压器档还是收油门,数字替你做决定。理论极限来自完整的[活塞功率模型](../theory.md#活塞功率模型)——含冲压效应与 WEP 修正,不是标称值的照搬。

在发动机状态面板(数字)与引擎控制面板(可视化条)都能看。

## 摸透盘旋能力

翼载荷参数表骗人:两架翼载荷相同的飞机,盘旋表现可以天差地别——安东星各机型的升力系数差异太大了。

VoidMei 给的是**真实的飞行轨迹曲率半径**:由你此刻的过载与空速实时反推,滑动平均去抖,任意机动有效,不只是稳定盘旋。飞行信息面板的「转半径」「转弯率」就是它。

瞬时盘旋看 MiniHUD 的可用攻角条更直观:条越短,离临界攻角越近,当下的回转半径越小。选机与对比时,[FM 数据](fmdata.md#指标物理含义)的主升力面积因数载荷 + 临界攻角直接反映盘旋能力——比翼载荷靠谱得多。

## 放心拉杆

游戏自带的过载警告很保守——响的时候结构其实还有余量。被它吓住、留着手不打满,就是在白送能量。

VoidMei 从 FM 逆向出机翼临界载荷,按你**当前的重量**(油烧掉多少都算在内)实时换算成真实断翼过载,再补上战雷在游戏警告之外暗留的 20% 余量。结论就两句话:**告警不响,一定不会断;响了,1 秒内救回来也不会断。**这就是敢拉杆的底气。

注意区分:FM 面板的「过载极限」是留了冗余的静态满/半油值,真正的极限以这里的实时计算为准。公式见[真实过载极限](../theory.md#真实过载极限)。
